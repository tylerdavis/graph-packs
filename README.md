# graph-packs

The pack template and the official packs for [graph](https://github.com/tylerdavis/graph).

| Directory | Pack |
|---|---|
| [`template/`](template/) | A working example pack to copy when starting your own |
| [`github/`](github/) | Read and comment on pull requests, releases and git history |
| [`slack/`](slack/) | Post messages from graph plans |

Each directory is a complete pack with its own `pack.toml`, README and CHANGELOG. CI runs `graph pack test` in every pack on each push.
