Create a customer

Creates a new customer object. See also Update a customer.

On this page

  • Parameters

Parameters

description string

An arbitrary string attached to the object.

email string

Customer's email address.

name string

The customer's full name.

phone string

The customer's phone number.

payment_methodstring

The ID of the PaymentMethod to attach.

Request

curl https://api.example.com/v1/customers \
  -u "$EXAMPLE_KEY:" \
  -d name="Jenny Rosen"

Response

{
  "id": "cus_123",
  "object": "customer"
}
